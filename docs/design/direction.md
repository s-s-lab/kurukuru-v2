# Kurukuru v2 デザイン方向

## 方向性

Kurukuruは「会議室のホワイトボードを、指で扱える精密な時間表にした道具」として設計する。マーケティングサイトではなく、日程調整を短時間で完了する操作ツールを主役にする。

- 背景：真白
- 主要色：Teal `#008f8a`
- 見出し・本文：Deep navy `#0f2b4f`
- 機能帯：Pale aqua `#eefbfc`
- 罫線：Blue gray `#cfe0e8`
- 回答色：◎緑、○青、△黄、×赤。必ず記号を併記し、色だけに依存しない。
- 角丸：入力・ボタン8〜10px、主要作業面14〜18px
- 影：階層が必要な箇所のみ薄く使用

## 中心操作

時間グリッドが最大の視覚要素。PCはドラッグ、スマートフォンは「塗る／移動」を明示的に切り替える。日付列を固定し、横移動可能であることをスクロールバーまたは端部表現で示す。

## 禁止事項

- 紫系グラデーション、ガラス表現、装飾目的の光彩
- カード内カード
- 意味のないバッジ・KPI・分析値
- マーケティング用ヒーローを実アプリ画面より優先すること
- 記号を色だけで区別すること
