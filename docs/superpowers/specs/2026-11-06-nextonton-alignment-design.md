# Kurukuru Nextonton Alignment Design

## Goal

Kurukuruの全画面をネクストトントンと同程度の1000px幅・高密度レイアウトへ揃え、イベント所要時間、06:00〜翌06:00の候補時間、公開ボードからの回答編集を提供する。

## Approved product decisions

- 主要コンテンツの最大幅は全ページ1000pxとする。
- モバイルでは左右10px以上の余白を保ち、時間表は横スクロールで表示する。
- 所要時間は任意の自由入力（最大100文字）とし、例は「1時間程度」とする。
- 時間範囲は06:00〜翌06:00の48個の30分枠とする。
- 時間表の見出しは正時だけ `06`、`07` のように表示し、30分位置は空欄とする。
- みんなの回答では回答者名を押すと、その回答の編集画面を開く。
- 回答編集はブラウザや端末に依存せず、イベントページを開ける人なら誰の回答でも編集できる。
- 既存のトークン付き編集APIは後方互換のため維持し、新しい公開編集APIを追加する。
- 注意事項にネクストトントン（https://nextonton.inotai.net/）へのリンクを掲載する。

## UI design

### Shared width

`.shell`、主催者候補日画面、回答モーダルを最大1000pxへ統一する。デスクトップでは中央配置し、モバイルでは既存の狭い外側余白を維持する。48枠を固定幅のセルで表示し、表だけを横スクロールさせる。

### Home page

見出しを次へ変更する。

> 30分単位の日程調整ツール　―参加者が回答すると通知がくるくる！

回答ボード例は日付列、回答者名、06時からの正時見出し、無表示の30分列を持つ実画面準拠の構成にする。履歴より後に「ご利用にあたって」を追加し、個人利用、広告なし、無料、収益なし、セキュリティ上のトラブルへの免責を記載する。参考サービスとしてネクストトントンへの外部リンクを表示する。

### Event creation

基本情報に「所要時間（任意）」を追加する。カレンダーは2か月表示を維持しながら、日付セル、見出し、操作ボタン、パネル余白を縮小する。時間表は48枠へ拡張し、正時だけ2桁時刻を表示する。一括選択の終了時刻も翌06:00まで扱う。

### Public response page

イベント概要に所要時間を表示する。公開ボードの回答者名はボタンとして表示し、押すとその回答を初期値にした回答モーダルを開く。新規回答ボタンは常に空の回答を開く。回答受付終了中は編集も新規回答もできない。

## Data and API design

### Event duration

`events.duration` を `text NOT NULL DEFAULT ''` で追加する。作成リクエスト、公開イベント、主催者イベント、主催者基本設定更新の型と検証へ `duration` を追加する。既存イベントは空文字として扱う。

### Timeline extension

候補枠を12〜59（06:00〜翌05:30）、境界を最大60（翌06:00）へ拡張する。時刻の文字列化では24時間を法として表示し、48は `00:00`、59は `05:30`、59の終了は `06:00` とする。DBの候補枠・確定枠制約を新しいマイグレーションで更新する。

### Public response editing

`PATCH /api/v1/events/:eventId/responses/:responseId` を追加する。認証トークンは要求しない。リポジトリは回答が指定イベントに属すること、イベントが公開中であること、候補枠が指定イベントに属することをトランザクション内で検証する。既存の `PATCH /api/v1/responses/:responseId` は維持する。

編集成功時は既存と同様に回答通知の更新イベントを生成する。公開イベントの回答IDはすでに返却されているため、新たな秘密情報は公開しない。

## Compatibility and migration

- 既存イベントの `duration` は空文字となり、表示を省略する。
- 既存候補枠12〜47はそのまま有効とする。
- 既存のローカル編集トークンは読み取り可能なままとするが、フロントエンドは公開編集経路を優先する。
- 作成済みイベントの時間範囲は主催者画面から48〜59の枠を追加できる。

## Verification

- ドメイン時刻、バリデーション、DBマイグレーション、イベント作成・取得、公開回答編集を自動テストする。
- ホーム、イベント作成、公開回答、主催者画面のコンポーネントテストを更新する。
- 全テスト、型検査、ビルドを実行する。
- 1000px幅のデスクトップとモバイルで、横スクロール、時刻見出し、名前クリック編集、注意事項リンクをブラウザ確認する。
